# HR Analytics Dashboard – Attendance & Workforce Insights

## 🔍 Project Overview
This project focuses on HR analytics and workforce attendance analysis, using Excel for data collection and preparation and Power BI for interactive visualization and insights.

The objective is to analyze employee attendance patterns, identify trends related to presence and absenteeism, and provide actionable workforce insights to support HR decision-making. The project simulates a real-world HR analytics use case commonly handled by data and BI analysts.

---

## 🎯 Project Objectives
- Collect and organize employee attendance data using Excel  
- Clean, validate, and prepare HR datasets for analysis  
- Analyze attendance trends and workforce patterns  
- Build interactive dashboards to support HR reporting  
- Enable data-driven workforce and policy decisions
